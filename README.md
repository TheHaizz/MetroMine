# ☣️ METRO ROYALE — Tactical Launcher (Forge 1.20.1)

Кастомный тактический лаунчер для клиента **Minecraft Forge 1.20.1** по мотивам режима **Metro Royale** (PUBG Mobile) в визуальном стиле **STALCRAFT: X**.

## 🎖️ Ключевой функционал лаунчера

### 1. Тактический интерфейс в стиле STALCRAFT: X
- **3D-модель бойца**: интерактивная модель в тяжёлой броне 6 уровня Metro Royale (*DeltaLxKoopa Level 6 Armor*). Поддерживает вращение мышью на 360°, отдаление и тактическое освещение бункера.
- **Карточка бойца**:
  - Позывной бойца (по умолчанию: `Boar345345`).
  - Уникальный 9-значный **Metro ID** (с кнопкой быстрого копирования в буфер).
  - Ранг доступа (`Ликвидатор`, `Легенда Метро`, `Мародер`, `Штурмовик`, `Сталкер`, `Администратор`).
  - Плашка клана: `[TAG] Название` или `Без клана`.
- **Звуковой движок (Web Audio API)**: тактические щелчки кнопок, радиопомехи и треск счетчика Гейгера.

### 2. Система кланов
- Кнопка **`+ СОЗДАТЬ`** / **`УПРАВЛЕНИЕ КЛАНОМ`** в карточке профиля.
- Вкладки управления:
  - **Мой клан**: статус, девиз, список участников с коронкой лидера, кнопка выхода.
  - **Создать клан**: ввод названия (3–24 символа), уникального клантега (2–6 символов в формате `[TAG]`) и девиза. Создатель автоматически назначается лидером.
  - **Список кланов**: глобальный каталог кланов сервера с фильтрацией и поиском, а также кнопкой вступления в 1 клик.

### 3. Скрытая панель Администратора (`cewux`)
- Доступ защищён паролем со звёздочками (`•••••`) и кнопкой показа/скрытия.
- Поддерживает раскладки: латиницу (`cewux`), кириллицу (`суцгч`, `севух`).
- Возможности администратора:
  - Выдача любого ранга (`Легенда Метро`, `Ликвидатор`, `Администратор` и др.) по нику.
  - **Выдача ранга незарегистрированному игроку**: если игрока ещё нет в базе, система автоматически регистрирует ему профиль и привязывает указанный ранг. При первом входе игрок сразу получает выданные привилегии.
  - Просмотр списка всех зарегистрированных бойцов в реальном времени.

### 4. Автоматический запуск игры
- Нажатие большой рубиновой кнопки **«В БОЙ»** запускает многоэтапную проверку:
  1. Синхронизация никнейма и UUID с профилем PolyMC.
  2. Проверка библиотек Forge 1.20.1 и модов.
  3. Прямое автоматическое подключение к серверу `governors-redirected.tun.ply.gg`.

## 📦 Установочный пакет (Инсталлятор `.exe`)

Для удобного распространения и установки лаунчера собран полноценный инсталлятор Windows:

- **Путь к инсталлятору на Рабочем столе**:  
  `C:\Users\user\Desktop\MetroRoyaleLauncher-Setup.exe`
- **Копия в каталоге лаунчера**:  
  `C:\Users\user\Desktop\launcher\MetroRoyaleLauncher-Setup.exe`
- **Размер**: ~115 МБ (сжатие Ultra LZMA Solid).
- **Особенности инсталлятора**:
  - Полный мастер установки на русском языке.
  - Возможность выбора директории установки (по умолчанию `%LOCALAPPDATA%\Programs\MetroRoyaleLauncher`).
  - Создание ярлыков на Рабочем столе и в меню «Пуск».
  - Запись в реестр Windows и интеграция с панелью «Установка и удаление программ».
  - Чекбокс автоматического запуска лаунчера сразу после завершения инсталляции.

## 🛠️ Разработка и сборка из исходников

Проект расположен в: `C:\Users\user\.gemini\antigravity\scratch\metro-royale-launcher`

### Скрипты `package.json`:

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки (Сервер API + Vite)
npm start

# Компиляция веб-клиента Vite
npm run build

# Бандл бэкенд-сервера через esbuild
npm run bundle-server

# Быстрая сборка unpacked версии
npm run pack

# Компиляция NSIS-инсталлятора
npm run dist
```

### Структура файлов:

